# TT-02 · Тривога

Прошивка для голосового асистента TT-02 (плата **AiKoder S3 LCD**: ESP32-S3, екран JD9853, кодек ES8311) на базі відкритої [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) v2.2.6 та [порту плати від iuridomingos](https://github.com/iuridomingos/aikoder-s3-lcd-esp32), з доданим модулем повітряних тривог.

## Що вміє

- **Тривоги без токена** — дані з `ubilling.net.ua/aerialalerts` (як у лаунчері «Вітальня»), опит кожні 20 с, автоматичне перемикання між піджерелами, якщо одне не відповідає.
- **Тривога в домашньому регіоні** (за замовчуванням — м. Київ) → сирена + екран з мапою України: області з тривогою червоні, вгорі «ПОВІТРЯНА ТРИВОГА», внизу — скільки триває.
- **Відбій** → мелодія відбою + зелений заголовок, через 20 с — знову звичайний вигляд.
- Під час тривоги екран не тьмяніє.
- Після увімкнення одразу показується мапа (обличчя робота — лише якщо сховати мапу кліком). Під час розмови внизу видно «Слухаю…» / «Говорю…».
- Голосовий асистент працює як раніше (xiaozhi.me), плюс нові голосові команди:
  - «Скільки годин?» / «Яка сьогодні дата?»
  - «Гучніше» / «Тихіше» / «Гучність 60»
  - «Є тривога?» / «Де зараз тривога?»
  - «Покажи годинник» / «Покажи мапу тривог» / «Покажи обличчя» (вибір запамʼятовується)
  - «Вимкни звук тривоги» / «Увімкни звук тривоги»
  - «Мій регіон — Львівська область»
  - «Тест повітряної тривоги»

## Кнопки

| Дія | Що робить |
|---|---|
| Клік кнопки живлення | наступний екран: мапа → годинник → обличчя асистента |
| Подвійний клік кнопки живлення | тестова тривога (~25 с) |
| Утримання кнопки живлення | вимкнути |
| Клік основної кнопки | почати / зупинити розмову |
| Утримання основної кнопки | налаштування Wi-Fi |

## Прошивка з Мака

1. Завантажте `tt02-trivoga-full-16MB.bin` з [Releases](../../releases/latest).
2. Підключіть TT-02 кабелем і виконайте в Терміналі:

```bash
cd ~/Downloads
python3 -m esptool --port /dev/cu.usbmodem1101 -b 921600 write_flash 0 tt02-trivoga-full-16MB.bin
```

3. Після перезавантаження пристрій створить Wi-Fi точку `Xiaozhi-XXXX` — підключіться до неї з телефону й вкажіть домашню мережу.
4. Пристрій продиктує / покаже 6-значний код — додайте його на [xiaozhi.me](https://xiaozhi.me) (пристрій прошито заново, тож прив'язку треба зробити ще раз).

## Повернути заводську прошивку

```bash
python3 -m esptool --port /dev/cu.usbmodem1101 -b 921600 write_flash 0 ~/tt02_backup.bin
```

## Як збирається

GitHub Actions (`.github/workflows/build.yml`): генерує кириличні шрифти (`lv_font_conv`, Inter), клонує xiaozhi-esp32, накладає `patches/xiaozhi.patch` і плату з `board/`, збирає в `espressif/idf:v5.5.4` і публікує реліз.

- `board/aikoder-s3-lcd/alert_monitor.*` — модуль тривог (опит, мапа, звуки, голосові команди).
- `tools/make_map.py` — растеризує мапу областей (ті самі контури, що у «Вітальні») у `ua_map.h`.
- `tools/make_sounds.py` — генерує сирену / відбій / сигнал у Ogg Opus → `alert_sounds.h`.
